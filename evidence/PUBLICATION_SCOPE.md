# Evidence snapshot

This folder contains selected cited reports, measurements, figures and implementation material from the November 25, 2026 consolidation. Historical documents can refer to additional artifacts that are not distributed here. Local machine paths in the published copies were replaced with neutral WORKSPACE/DRIVE placeholders. Numerical results were not altered.

Four checkpoint references link to explanatory pages rather than model payloads. Fourteen directory references have scoped index pages; their contents were not copied recursively. No pretrained model download, cache or dataset directory is included.

See the [source manifest](../data/source_manifest.json) for original source fingerprints, published-file fingerprints and representation types. The [project directory](../projects/README.md) is the recommended starting point for interpretation.

## Reading historical sources

Source documents retain their original experimental descriptions. Statements such as "all files are in this folder" refer to the original workspace, not this curated release. Deep-linked Markdown and HTML reports carry a publication-scope notice. Some historical local links and figures remain unavailable; no full reproduction is claimed. Only three Python implementation files are included.

PNG text, EXIF and time metadata have been removed without changing plot pixels. Source hashes distinguish original artifacts from these publication copies.
