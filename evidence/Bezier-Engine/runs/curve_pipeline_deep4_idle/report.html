Raw measurements and environment · Plain-text report · Frozen protocol

Intel(R) Core(TM) Ultra 7 265KF; NVIDIA GeForce RTX 5090; PyTorch 2.10.0+cu128. 108 schedule/workload configurations, 3 randomized rounds per configuration, 3 complete execution(s) per timed observation. All numbers below are median wall time for the complete workload, in milliseconds; lower is better.

The GPU producer uses the project's PortsAndCurve MLP and control-point mapping. The CPU evaluates the same cubic Bernstein weighted sum. Fixed sample-time coefficients are cached equally in every schedule. Schedules share identical reproducibly generated random inputs and random weights, as specified by the recorded settings and frozen source; this is an FP32 execution experiment with TF32 disabled, without training or model-quality claims.

Weights use seed 20261125; inputs use a separate CPU generator with seed 20261126. The separate input generator gives shallow and deeper networks identical inputs despite different parameter counts. Weight values differ across depths; schedules within each depth use identical weights and inputs.

Control-point hidden layers are the nonlinear layers inside the network that calculates the four control points. Their architecture is input width → router width repeated once per hidden layer → 12 output values, with SiLU after each hidden layer. This count is separate from recursive tree levels and does not count the sphere's expert layers. The child embedding is used only between nonterminal levels in the synthetic tree.
