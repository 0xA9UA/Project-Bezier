Compressing pretrained models with Bézier curves

Twenty fixed comparisons on two pretrained SmolLM2 base checkpoints (135M and 1.7B advertised parameters). Each codec changes the same transformer linear weights; embeddings, output tying, normalization and biases are preserved and counted. WikiText-2 test evaluation scores 65,536 next tokens in 128 disjoint windows. ARC-Easy uses 1,024 fixed science questions; primary answers maximize token-length-normalized answer log-likelihood. The unnormalized metric and all predictions are saved. Codec fitting uses weights only, with no test-driven tuning, fine-tuning or recovery training.

Quality targets

Targets were fixed before results: at most a 10% relative perplexity increase, at most a two-percentage-point QA accuracy loss, and retention of at least 95% of questions the reference answered correctly. All three must hold. The smallest eligible codec is selected using validation results, then its test outcome is reported. Meeting these limited thresholds does not prove every fact survives.

Runtime and reconstruction

Every artifact is decoded into the original dense float16 architecture before evaluation. Smaller stored files therefore do not imply smaller steady-state GPU parameter memory or faster inference. Decode time includes file access and device copies into an existing model; the OS file cache may be warm. Prefill timing excludes decoding, loading, tokenization and transfer, uses SDPA and synchronized wall timing. Allocator peaks are not physical memory traffic. The RTX 5090 is a desktop GPU; scheduling and clocks can vary.

Interpretation limits

This tests one pretrained model family at two sizes, one text corpus and one science-question dataset. ARC includes reasoning and language comprehension; it is not a complete or pure inventory of stored facts. Pretraining overlap with public benchmarks is unknown. The generic quantization and randomized SVD baselines are not activation-aware GPTQ/AWQ or SVD-LLM. No recovery training was used. Direct curve fitting assumes local numerical smoothness of weights; another representation or compression-aware training may behave differently. Codebook Bézier still stores an index for every weight. Sorted Bézier pays for the permutation. These methods do not test sphere routing.
