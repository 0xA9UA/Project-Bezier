Bezier-Steer verified examples

Different programs, identical verified behavior

These are actual saved outputs from the held-out test tasks. Every program passes all 16 possible Boolean inputs. Its displayed curve uses the same latent draw as its saved generation. Curves may overlap: geometric distance is not a measure of semantic difference. Dead instructions can appear in the raw code; the diversity count removes them and other simple equivalent rewrites.
